# Experiment 001 — kernel vertical slice

Status: PLANNED

Question: Can the five-primitive Take-2 kernel plus PD execute a real consequential
workflow with less operating-surface complexity and stronger epistemic traceability
than the legacy path?

The first case must be low-risk, real, bounded, and capable of producing a material
state transition. It must not require migrating a whole research project.

Predeclared observations:
- baseline identity;
- exact target/job;
- PD capabilities selected and why;
- rivals/OPEN coordinates;
- transition authority;
- files/objects read and changed;
- validation result;
- elapsed time where the tool surface exposes it;
- manual interventions;
- number of durable surfaces touched;
- post-change reentry result.

Failure conditions:
- a consequential change bypasses Transition;
- causal language outruns observations/discriminators;
- a new semantic distinction forces a new registry without strict-gain evidence;
- current state cannot be reconstructed from kernel records;
- legacy authority is silently displaced;
- experimental PD output is treated as stable evidence.

Success is evidence for continuing the kernel experiment, not proof of global superiority.
