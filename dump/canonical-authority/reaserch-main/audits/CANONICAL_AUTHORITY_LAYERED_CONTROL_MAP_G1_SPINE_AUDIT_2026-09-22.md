## 2. G1.1 HM-001 reconstruction

Target: preserve and validate the fixed Rashi-Ramban proposition-level disagreement,
second-order scope, and truth-directed criterion.

Candidate spine:

`FIX -> TYPE -> BOUND -> TARGET -> CONTROL`.

HM-001 transition logic:

1. FIX identifies the exact case. Without it, downstream truth-directed analysis lacks
   a stable target.
2. TYPE converts the interpretive collision into explicit incompatible truth-apt
   propositions. Historical names alone do not supply the proposition pair.
3. BOUND prevents the project from silently becoming a first-order grammar paper.
4. TARGET states what success means for the later evaluator.
5. CONTROL makes the validated fixed case available to downstream source and route
   analysis.

Destructive test: removing TYPE, BOUND, or TARGET materially changes the target
achievement conditions. FIX and CONTROL remain load-bearing as case identity and
downstream handoff.

Rival-spine test: a history-first ordering and a grammar-first ordering both either add
non-load-bearing discovery chronology or change the goal. The candidate spine survives.

Result: PROVISIONAL_SPINE. Current frontier is preservation and paper-facing edition
closure, not conceptual expansion.

## 3. G1.2 HM-001 reconstruction

Target: reconstruct selected Jewish response structures in native context before case
application.

Candidate spine:

`ADMIT -> VERIFY -> RECONSTRUCT -> TYPE -> PROFILE -> BOUND`.

The audit exposes two previously compressed dependencies.

First, ADMIT is distinct from VERIFY. Recovering and verifying a source does not explain
why that response family belongs in the comparison set.

Second, BOUND is distinct from PROFILE. A high-quality module reconstruction does not
establish exhaustive coverage of materially different response families.

Destructive tests:

- remove ADMIT: the project can accumulate modules without a principled comparison-set
  rationale;
- remove VERIFY: native reconstruction loses stable evidence identity;
- remove RECONSTRUCT: typing becomes projection rather than source-grounded analysis;
- remove TYPE: heterogeneous outputs become silently commensurable;
- remove PROFILE: repeated case application loses a stable source-side object;
- remove BOUND: broader claims can exceed the admitted corpus.

ADMIT and BOUND are conditionally load-bearing for the strongest broader claims even
when the fixed-case result remains unchanged.

Rival-spine test: source-first and discovery-history orderings fail because neither
distinguishes selection grounds from source verification and coverage bounds.

Result: PROVISIONAL_SPINE with an OPEN frontier.

Deepest live generator: the response-family admission and coverage criterion. The next
ceiling move here is not indiscriminate source accumulation. It is a compact account of
what counts as a materially different response family, why the current families are
admitted, what would justify adding another family, and how non-exhaustiveness limits
the broader conclusion.

## 4. G1.3 HM-001 reconstruction

Target: test admitted structures through the source-to-case pathway.

Candidate spine:

`PROFILE -> TRACE -> DISCRIMINATE -> RECOGNIZE -> [COMPOSE] -> OUTPUT`.

The historical singleton-only interpretation already failed a hostile test and was
repaired by package TRACE. The current package-aware route preserves singleton
embedding and separates route-level grounds from case-level composition.

Destructive and rival-spine tests therefore inherit the strongest current audit state:

- PROFILE is required typed setup;
- TRACE is load-bearing;
- DISCRIMINATE is load-bearing for adjudicative asymmetry;
- RECOGNIZE is load-bearing for evaluator-relative usability;
- COMPOSE is conditionally load-bearing only when several completed grounds materially
  conflict;
- collapsing package TRACE into COMPOSE loses the distinction between creating one
  ground and aggregating completed grounds.

Result: PROVISIONAL_SPINE with a FROZEN default frontier. Reopen only under the existing
theory-freeze triggers or new evidence that defeats the package-level TRACE obstruction.

## 5. G1.4 HM-001 reconstruction

Target: state the strongest bounded conclusion while preserving output-type
distinctions.

Candidate spine:

`RESULTS -> SEPARATE -> BOUND -> C_case -> {C_method, C_disciplinary}`.

The main hidden step is that the fixed-case result, general method claim, and broader
disciplinary implication have different evidential dependencies.

Destructive test: removing SEPARATE or BOUND permits legitimacy, authority, explanatory
power, and truth adjudication to collapse, or permits the fixed case to carry broader
claims it does not independently prove.

Rival-spine test: a single undifferentiated conclusion node is shorter but loses claim
typing and evidence-layer separation. It is rejected.

Result: PROVISIONAL_SPINE with a STRONG frontier. Remaining work is manuscript-level
claim calibration rather than a stronger fixed-case verdict.

## 6. G1.5 HM-001 reconstruction

Target: establish provenance, reproducibility, novelty boundaries, and publication
framing.

The strongest spine is branching, not linear:

`{PROVENANCE + NOVELTY + MANUSCRIPT + JOURNAL} -> READY`.

Each branch is independently necessary for internal submission readiness.

Destructive test:

- remove PROVENANCE: paper-facing claims are not fully recoverable;
- remove NOVELTY: the contribution delta is not defensible against nearest neighbors;
- remove MANUSCRIPT: no reader-visible article exists;
- remove JOURNAL: contribution hierarchy and scope remain venue-indeterminate.

Rival-spine test: the linear model
`sources -> novelty -> manuscript -> journal` falsely implies that one branch must
wait for total closure of the previous branch and encourages progress in one branch to
stand in for readiness in another. The conjunctive convergence model fits current
project behavior better: drafting can proceed while bounded source and novelty closure
continue, but READY remains false until all internal branches close.

Result: PROVISIONAL_SPINE with an OPEN frontier.

## 7. Current ceiling distribution

The audit changes the meaning of the live frontier.

The theory core is not the dominant open region. It remains frozen under the existing
reopen rule.

The major internal ceiling space is now localized to two G1 regions:

- G1.2: admission rationale, materially distinct response-family coverage, and remaining
  paper-facing verification;
- G1.5: provenance closure, full-text nearest-neighbor closure, manuscript execution,
  and journal-specific framing.

G1.1, G1.3, and G1.4 mainly constrain preservation and calibration.

This result explains why additional global ceiling scans now produce lower expected
value than work on specific open layers.

parallel.

## 9. Bounded convergence

A further recursive pass into all G2 goals is not required for this implementation.

The current G1 reconstruction already localizes the strongest open internal generators,
and G2 recursion would add control cost before evidence that an unresolved G2 dependency
is limiting the current publication ceiling.

Reopen G2 spine construction when one of these conditions occurs:

1. a G1 frontier cannot be resolved because its child dependency is ambiguous;
2. a new source or counterexample changes a G1 result;
3. manuscript execution exposes a hidden child dependency;
4. a hostile reviewer attack identifies a G2-level vulnerability;
5. a G1 spine repeatedly generates defects that cannot be explained at G1 resolution.
