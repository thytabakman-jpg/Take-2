## Variation found

The historical project changed framing over time.

Earlier framing:
- mesorah-centered convergence argument
- multiple attempted symmetry breakers
- further truth-discriminating criterion

Later framing:
- bounded second-order comparison
- selected Jewish epistemic, interpretive, institutional, transmission, authority, and privileged-access structures
- typed source-to-case pathway
- proposition-specific differential truth/evidential support
- case-operational effect
- no unsupported universal negative or exhaustiveness claim

These are not treated as identical formulations.

The migration preserves the stable core shared across them while giving the later user-confirmed architecture priority where the older framing was explicitly revised.

## Stable migrated core

The source-grounded evidence supports:

1. Fixed primary case:
   Rashi and Ramban on Genesis 1:1 make incompatible proposition-level claims relevant to the project.

2. First-order boundary:
   The project does not need to decide the ultimate grammatical verdict.

3. Second-order target:
   The project tests what selected Jewish structures can contribute to assessing the incompatible truth-apt claims.

4. Typed application requirement:
   Source content and native function must be distinguished from transfer, truth relevance, proposition linkage, case instantiation, and case-operational effect.

5. Adjudicative success criterion:
   A route counts as truth-adjudicative only when it provides proposition-specific differential support operationalized for the fixed case.

6. Bounded current result:
   No currently admitted reconstructed route yet completes the required asymmetric comparison.

7. Publication endpoint:
   The project aims at a rigorous peer-reviewed paper with bounded novelty and corpus claims.
