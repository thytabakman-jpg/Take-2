# Canonical Authority Source-Package TRACE Audit

Date: 2026-09-22

Status: strong candidate result; isolated branch; canonical promotion pending backend
recovery reconciliation.

## Question

Does failure of every individual admitted authority route at TRACE entail failure of
the admitted corpus at TRACE?

## Hostile counterexample

No.

Two source structures can each lack a complete source-to-target path while jointly
supplying complementary source-grounded premises.

Therefore:

`for all i, not TRACE(H_i,tau)`

does not entail:

`for all X subseteq A, not TRACE(X,tau)`.

The earlier singleton-only obstruction formulation was too strong.

## Repair

Let `AdmPkg_A` denote independently admissible nonempty source packages drawn from
the admitted corpus A.

For X in `AdmPkg_A`, define:

`PackageGround_e(X,tau)`

iff there exists Delta such that:

- TRACE(X,tau,Delta);
- Delta DISCRIMINATES the rival propositions concerning tau;
- evaluator e can RECOGNIZE and use Delta on warranted grounds.

Joint use itself cannot be smuggled in as supplementation. Package admissibility and
every material cross-source bridge require independent grounds.

## Distinction from COMPOSE

Package TRACE:
several source structures jointly establish one target-indexed ground.

COMPOSE:
several already-established target-indexed grounds require aggregation or defeat.

The two operations are not interchangeable.

## Current seven-module test

Admitted modules:

- H_P pluralism and determination;
- H_M protected reception;
- H_A authority and error;
- H_X authenticated prophecy;
- H_R Ramban creation tradition;
- H_L loss and reconstruction;
- H_G generational hierarchy.

### Packages excluding H_R

No other currently reconstructed module contains the case-proximate claim that
Ramban's creation interpretation participates in received esoteric creation knowledge.
Such packages therefore lack the relevant source-side connection to I_S.

### Packages including H_R

H_R establishes that Ramban invokes received esoteric knowledge concerning creation,
but the inspected source does not identify the specific syntactic proposition I_S as
an item of that received knowledge or otherwise establish that the received content
truth-supports I_S.

No other module supplies that missing proposition-specific edge.

- H_M distinguishes received from reason-derived material but does not classify I_S.
- H_P supplies legitimacy/determination rather than I_S coverage.
- H_A supplies institutional authority/error rather than I_S coverage.
- H_X supplies an authentication structure without an instantiated prophecy about I_S.
- H_L supplies loss/reconstruction structure rather than I_S coverage.
- H_G supplies hierarchy/stature rather than I_S coverage.

Therefore combining H_R with any currently reconstructed subset does not complete the
missing edge.

## Candidate obstruction result

Relative to the current typed module content and independently admissible source use:

`for every X in AdmPkg_A, not TRACE(X,I_S)`.

Consequently no package reaches DISCRIMINATE or evaluator-specific RECOGNIZE, and
COMPOSE remains dormant for the fixed case.

## Evaluator invariance corollary

Because the current obstruction occurs before RECOGNIZE:

`for every relevant evaluator e, no PackageGround_e(X,I_S)`

for any currently admissible package X.

Thus evaluator typing remains material to the general method and positive control but
does not change the present bounded case result while the package-level TRACE
obstruction holds.

## Reopen condition

Reopen this result whenever:

- the admitted module set changes;
- source recovery adds target-relevant content to a module;
- a source-grounded cross-module bridge is recovered;
- the target proposition changes;
- the exact interpretation of an existing primary source changes materially.

This is a corpus-bounded obstruction certificate, not a universal negative.
