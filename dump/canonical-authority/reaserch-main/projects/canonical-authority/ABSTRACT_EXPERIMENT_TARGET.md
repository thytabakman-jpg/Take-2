# Canonical Authority — Frozen Abstract Experiment Target

Status: DERIVED EXPERIMENT TARGET / NOT MANUSCRIPT AUTHORITY
Date: 2026-09-24
Purpose: controlled target for comparing full-capability behavior on a compressed abstract versus the full project

When canonical Jewish interpreters make incompatible factual claims, shared canonical standing does not by itself explain what grounds a later evaluator has for favoring one as true. This paper develops a source-grounded method for comparing heterogeneous Jewish epistemic, interpretive, institutional, transmission, authority, and privileged-access structures against one fixed truth-apt target while preserving their native functions. Using the Rashi-Ramban disagreement over Genesis 1:1 as a worked case, the method first reconstructs each admitted structure in context and then distinguishes three adjudicative jobs: TRACE, whether an independently admissible source package supplies a licensed and source-attributable path to the target; DISCRIMINATE, whether that path asymmetrically supports one rival; and RECOGNIZE, whether a third-party evaluator has warranted grounds to identify and use that discriminator. Authenticated prophecy functions as a positive control showing that traditional truth-directed success is possible in principle. Across the current purposive, non-exhaustive seven-module corpus, however, no independently admissible source package completes TRACE to the exact disputed proposition, so the fixed case remains unresolved at that upstream stage. The analysis therefore yields a bounded case result and a broader methodological claim: religious authority is functionally differentiated and target-relative, and inferential force introduced by bridge or composition machinery must be attributed to that added machinery rather than retroactively to the source. Where several completed grounds conflict, a separately licensed composition or defeat relation is required.
