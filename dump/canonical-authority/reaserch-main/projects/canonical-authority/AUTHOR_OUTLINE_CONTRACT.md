# Canonical Authority — Author Outline Contract

Status: current working contract
Date: 2026-09-24

## Job

Define the clean review surface the user approves before prose drafting.

## Source objects

- RESEARCH_ARCHITECTURE.yaml
- MANUSCRIPT_BLUEPRINT_FINAL_2026-09-24.md

## Required content

The author outline must show:
- paper goal and question;
- fixed case and scope;
- seven section jobs;
- all twenty-one substantive movements;
- what each movement says;
- human-readable source anchors;
- what each movement earns;
- section-to-section transitions;
- contribution hierarchy;
- bounded novelty and limits.

## Excluded content

Do not include by default:
- tool names;
- controller logic;
- liveness/termination machinery;
- artifact registries;
- repository hashes;
- backend readiness taxonomies;
- internal synchronization rules;
- audit history.

## Completion

The outline is complete when no unresolved planning decision remains that would change the
paper's argument order, intended claim, or substantive allocation.

Remaining work may still include:
- prose realization;
- exact quotation/citation formatting;
- sentence-level notation;
- genuinely external comparator evidence needed for final wording.

## Approval meaning

User approval means:
"this is the paper plan to write."

It does not certify submission readiness.

## Reopen

Refresh the author outline only when an upstream change alters:
- section/movement structure;
- intended substantive claim;
- source placement;
- result/scope;
- contribution hierarchy.
