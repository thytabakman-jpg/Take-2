## ARGUMENT SPINE

**CANON:SPINE:001**

`A -> Q -> H[F] -> R -> B -> C`

**Fixed collision**
→ **Third-party adjudication question**
→ **Admitted source-grounded response space**
→ **Source-to-target application**
→ **Adjudicative success requirement**
→ **Bounded result and contribution**

The spine is the protected macro argument order. Section numbering and manuscript headings can change; the substantive order cannot change without separate spine review.

### R — Source-to-target application

`R[source-grounded content -> native domain -> native function -> licensed transfer -> truth relevance -> proposition-specific linkage -> case instantiation -> evaluator warrant/recognizability -> case-operational effect]`

### B — Adjudicative success requirement

`B** = T + L + I + W`

where:

- `T` = warranted truth or evidential relevance in the relevant domain
- `L` = linkage to the actual disputed proposition
- `I` = asymmetric instantiation between the rival claims or claim-bearers
- `W` = warranted third-party access, authentication, or recognizability sufficient to rely on the asymmetry

### Spine preservation rule

Every material discovery or ceiling-raising move attaches to the smallest spine node whose content, support, scope, implication, or dependency it changes.

A move that requires replacing the identity of `A -> Q -> H[F] -> R -> B -> C` is a new-program or goal-change candidate, not an ordinary manuscript improvement.

## READER-LEVEL REFINEMENT

The reader-facing refinement of the spine is:

`A -> Q -> PROFILE(H[F]) -> TRACE -> DISCRIMINATE -> RECOGNIZE -> [COMPOSE when several completed grounds materially conflict] -> C`

This is a refinement of the spine, not a replacement for it.

### Reader journey

The intended reader movement is:

1. Encounter a real proposition-level disagreement.
2. Understand why the question is one of third-party adjudication rather than merely disagreement explanation.
3. See that different Jewish response structures perform different native jobs.
4. Learn that taking a road seriously imports substantive commitments.
5. See the requirement for a licensed source-to-target path.
6. Distinguish target-specific discrimination from mere authority, legitimacy, transmission, or explanation.
7. Distinguish an objective discriminator from the evaluator's warranted ability to use it.
8. Understand that the present corpus stops at the trace problem rather than forcing a downstream verdict.
9. Leave with the broader fixed-target method and its bounded implications for religious authority.

This reader journey is a working control for manuscript construction, not a substitute for the canonical spine.
