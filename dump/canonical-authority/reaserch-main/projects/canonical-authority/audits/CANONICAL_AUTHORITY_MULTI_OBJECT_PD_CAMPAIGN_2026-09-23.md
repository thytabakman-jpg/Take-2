# RUN 1 — Case × Pluralism × Authority × Revelation/Transmission × PD

Objects:

## Pair/joint synthesis

### 1. Pluralism + authority

H_P can preserve legitimacy while also allowing halakhic determination. H_A shows that institutional legal authority can coexist with recognized error. H_M distinguishes received content from reason-derived legal interpretation.

Joint result: legal settlement, legitimacy, provenance, and descriptive truth remain different output types. Combining them does not generate a truth relation to I_S.

Classification: NO_NEW_TRACE.

### 2. Authority + revelation/transmission

This is the strongest candidate combination because reception/authority can authenticate a channel while prophecy or esoteric tradition can in principle carry truth-directed content.

Joint test:
- channel authentication or protected provenance is not target coverage;
- target coverage is not asymmetric selection unless I_S itself is linked;
- asymmetry is not evaluator-usable without recognition/warrant.

H_X remains a positive control in principle. H_R remains case-proximate. H_M can classify reception. None supplies the missing edge that I_S itself is the content of the privileged reception.

Classification: COMPOSES_WITH structurally, but TRACE remains incomplete.

### 3. Pluralism + revelation

Pluralism can explain how rival canonical positions retain legitimacy. Revelation could in principle discriminate truth if proposition-specific. Pluralism does not supply the missing proposition-specific content of revelation, and revelation does not convert canonical legitimacy into truth evidence.

Classification: ORTHOGONAL_FUNCTIONS_WITHOUT_TRACE_COMPLETION.

### 4. Full five-object joint run

The only plausible joint completion has the shape:

authenticated/received channel
-> proposition-specific coverage of I_S
-> asymmetric support for P_R or P_N
-> evaluator recognition.

The current source package can strengthen the first node and contextualize the last, but the second edge remains absent.

PD therefore locates the obstruction more sharply:

\[
\text{channel status} \not\Rightarrow \text{target content}.
\]

This is the same package-level TRACE obstruction in a more compressed form.

## Run 1 result

No new selector.

Incremental methodological yield: the current package obstruction can be represented as a missing TARGET-CONTENT edge rather than a generic failure of "authority."

This is a useful compression, but it does not change the bounded case verdict.

# RUN 2 — Loss/Reconstruction × Generational Hierarchy × Interpretive Method × Canonical Status × PD

Objects:

## Joint findings

### 1. Explanatory cluster

L and G can jointly explain why later disagreement or reconstruction occurs:
- material can be forgotten;
- later agents can differ in stature, memory, or method;
- interpretive reconstruction can generate rival conclusions;
- canonical status can preserve both outputs socially/institutionally.

This yields an explanatory model of disagreement persistence.

It does not yield a proposition-specific truth selector.

Classification: F5 EXPLANATION cluster.

### 2. Hidden inference exposed

A tempting inference is:

earlier/greater/received/canonical
-> more reliable
-> true on I_S.

PD decomposes this into at least two missing bridges:
1. status/stature -> reliability for this proposition type;
2. reliability -> asymmetric support in this case.

Neither is supplied merely by combining L, G, M, and K.

Classification: UNLICENSED_DOUBLE_BRIDGE.

### 3. Reconstruction does not inherit lost authority automatically

Even if an earlier authoritative answer once existed and was lost, a later reconstruction does not inherit the epistemic status of the lost answer merely because it aims to recover it.

This is stronger than saying H_L is merely explanatory. It identifies a non-transmission principle:

\[
\text{authority of lost item}
\not\Rightarrow
\text{authority of reconstruction}.
\]

Status: candidate general result, recoverable from existing provenance/transfer controls but newly salient in this cluster.

### 4. Canonical preservation can increase underdetermination

When multiple reconstructed interpretations become canonical, canonical status can preserve the rival set rather than reduce it.

This is not evidence against canonicality; it is a type result. Canonicality can stabilize membership in the admissible interpretive space while leaving truth selection unresolved.

Status: useful joint characterization; no case verdict change.

## Run 2 result

No new selector.

Incremental yield:
- explicit non-transmission principle for lost-authority -> reconstruction-authority;
- canonical preservation can stabilize an unresolved rival set.

Both strengthen explanatory/function typing rather than adjudication.

# RUN 3 — Functional architecture × PD

Objects:

## Pairwise and joint results

### 1. F3 does not entail F2

Normative settlement can determine practice while leaving descriptive truth unresolved.

This survives every combination with F4, F5, and F6 unless an independently licensed truth-directed bridge is added.

### 2. F4 can enable but not complete F2

Provenance classification can identify a source as received, derived, prophetic, institutional, or reconstructed. That can be a necessary input to a truth route. It does not by itself supply target coverage or discrimination.

Relation: SUPPORTS/CONSTRAINS, not SUPERSEDES.

### 3. F5 and F6 jointly explain failure without adjudicating

Explanation of disagreement plus inference constraints can show why a proposed selector fails. They can thereby rationally force F7 in a bounded inquiry without themselves selecting P_R or P_N.

This is a genuine composition:

\[
F5 + F6 \rightarrow F7
\]

when the explanation plus constraint exhausts the currently admitted selector candidates relative to the declared corpus.

The result is inquiry-relative suspension, not metaphysical indeterminacy.

### 4. F4 + F6 can block illicit portability

Provenance typing plus invalid-inference constraints jointly yield a general anti-portability rule:

success in one native function/domain cannot be moved to F2 merely because the source is authoritative.

This recovers and compresses a central current contribution.

### 5. Can individually non-F2 functions jointly become F2?

Yes in principle, but only if their licensed composition creates the missing truth-directed target edge rather than merely accumulating status.

Abstractly:

\[
\neg F2(x)\land\neg F2(y)
\]

does not imply

\[
\neg F2(x\oplus y).
\]

The current package-level TRACE machinery already protects against the invalid singleton-to-global inference.

Applied to the seven admitted modules, however, the needed target-content edge remains absent.

### 6. F7 is not merely failure

F7 has a positive epistemic role: it preserves the strongest warranted result when admitted alternatives remain outcome-material and no selector is licensed.

This makes F7 an output discipline, not merely an error code.

## Run 3 result

No new case selector.

Material conceptual yield:
- F5 + F6 can positively license bounded F7;
- F7 is a positive epistemic output discipline;
- non-F2 functions can jointly become F2 in principle, but only through an independently licensed truth-directed composition.

# RUN 4 — Connect Run 1 × Run 2 × Run 3 × PD

Objects:

R1 = adjudicative source-package cluster.
R2 = disagreement-generation/reconstruction cluster.

## Higher-order findings

### H1 — Two different kinds of "failure to select"

The combined run distinguishes:

Type A: MISSING TARGET CONTENT.
A source/channel may be authoritative, received, authenticated, or case-proximate but does not establish that I_S is the content carried.

Type B: MISSING TRANSFER/SELECTOR.
Relevant content/status exists, but moving from it to asymmetric truth support requires an unlicensed bridge, reliability rule, or composition selector.

The current fixed case is primarily Type A at package TRACE. Several rejected routes additionally exhibit Type B.

This distinction sharpens the obstruction map.

### H2 — Explanatory success can increase confidence in suspension without increasing truth evidence

R2 can explain why disagreement exists and persists. R3's F6 can rule out illicit transfers. Together they can strengthen the warrant for F7 while adding zero support to either rival.

Thus evidence about why no selector is currently licensed is epistemically valuable even when it is symmetric between P_R and P_N.

### H3 — Canonical authority architecture has three levels

The campaign compresses the project into three non-equivalent levels:

1. SOURCE/CHANNEL STATUS
   legitimacy, reception, authentication, stature, canonicality.

2. TARGET LINK
   does the source/channel actually bear on I_S, and how?

3. SELECTION/UPTAKE
   does the target link discriminate P_R/P_N, and can evaluator e warrantedly use it?

The current TRACE obstruction lies between levels 1 and 2.

This is a compression of PROFILE -> TRACE -> DISCRIMINATE -> RECOGNIZE, not a replacement.

### H4 — Package composition cannot repair a missing edge by accumulation

Adding more sources that establish level-1 status, explain disagreement, or constrain inference cannot by sheer accumulation produce level-2 target linkage.

A package can complete TRACE only when at least one licensed cross-source relation contributes the missing target-content edge.

This gives a useful stopping rule for future source expansion: search specifically for sources/bridges capable of changing level 2 rather than adding more level-1 support.

### H5 — Search-value result

For the fixed case, the highest-value new evidence is not another general source on authority, pluralism, hierarchy, or disagreement. It is evidence that can answer one of these:

- Is I_S itself claimed as received/esoteric content?
- Is there a source-grounded rule connecting the relevant received creation knowledge to I_S?
- Is there another independently admissible source that supplies that proposition-specific edge?
- Is there first-order evidence admitted into a revised inquiry that directly bears on I_S?

This is a research-routing result, not a change in the current article's bounded conclusion.

# Overall campaign verdict

The multi-object campaign did not overturn the current bounded no-selector result.

It produced no jointly admissible route that completes TRACE to I_S.

It did produce new or sharpened architecture:

1. Missing-target-content versus missing-transfer/selector are distinct obstruction types.
2. Lost authority does not automatically transmit to a reconstruction.
3. Canonical preservation can stabilize an unresolved rival set.
4. F5 explanation plus F6 inference constraint can positively license bounded F7 suspension.
5. F7 is a positive epistemic output discipline.
6. Source/channel status, target linkage, and selection/uptake form a useful three-level compression.
7. Package composition cannot repair a missing target-content edge merely by accumulating more status/explanatory sources.
8. Future search can be routed specifically toward evidence capable of supplying the missing level-2 target-content edge.

## Effect on current architecture

Case verdict: unchanged.

TRACE obstruction: preserved and sharpened.

Spine: no demonstrated change.

Potential ceiling effect: candidate compression and search-routing improvement. Under the current theory freeze, these findings require a separate strict-gain/non-regression evaluation before promotion into CANON:ARCH:001.
