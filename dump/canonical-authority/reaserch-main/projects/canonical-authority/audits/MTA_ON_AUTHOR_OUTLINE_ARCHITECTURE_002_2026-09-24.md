# Canonical Authority — MTA on Author Outline Architecture 002

Date: 2026-09-24
Status: EXECUTED / MATERIAL REFINEMENT / RELATIVE CLOSE
Target: separate clean review-outline architecture

## Job

Test whether the separate review-outline object is genuinely distinct, minimal enough,
and nonredundant relative to the internal blueprint and prose manuscript.

## Round 1 — duplication attack

Potential defect:
A separate outline can become a second uncontrolled copy of the manuscript plan.

Repair:
the clean outline is not an independent authority source.
It is a derived review surface whose protected content comes from:
- RESEARCH_ARCHITECTURE.yaml;
- MANUSCRIPT_BLUEPRINT_FINAL_2026-09-24.md.

Material delta:
its authority must be "working review surface," not canonical research authority.

## Round 2 — content resolution

Question:
Does the review outline need all twenty-one movements?

Finding:
yes, but not with backend fields.

Reason:
the user wants to walk through the whole paper before prose.
If movements are omitted, local argument decisions remain hidden until drafting.

Material delta:
retain all 21 movements, expressed as concise substantive outline units.

## Round 3 — source-resolution attack

Question:
How much source detail belongs in the clean outline?

Too little:
the user cannot see what evidence each part rests on.

Too much:
the outline becomes the source registry again.

Candidate:
show named source anchors at author-decision resolution:
Rashi, Ramban, Eruvin 13b/Ritva, Rambam Mamrim/Introduction, Horayot,
Temurah 16a, Shabbat 112b/Eruvin 53a, Yesodei HaTorah 9-10,
plus nearest-neighbor literature only where structurally relevant.

Material delta:
use human-readable source anchors, not registry metadata.

## Round 4 — "remaining work" attack

The clean review outline must not contain unresolved planning choices that the current
research can already decide.

Resolve now:
- H_P/H_M first in Section 3;
- H_A/H_L/H_G compressed in the middle;
- H_X/H_R receive strongest dedicated treatment;
- COMPOSE stays compact in Section 4;
- positive control precedes the actual negative result;
- Section 6 carries target-relative authority;
- final novelty is framed as bounded intersection novelty, not component novelty.

Remaining after outline approval:
only prose realization, exact quotations/citations, sentence-level notation, and final
literature wording where external comparator closure remains genuinely open.

Material delta:
review outline can be complete even when citation formatting/prose execution remains open.

## Round 5 — user approval semantics

The review outline is the object the user approves as "this is the paper."

Approval does not certify:
- submission readiness;
- final source normalization;
- peer-review success.

It certifies:
- paper architecture;
- argument order;
- content allocation;
- contribution hierarchy;
- planned evidence placement.

Material delta:
approval scope must be explicit.

## Round 6 — closure

No further material object factor appears.

Current model:

B internal blueprint
-> A clean review outline
-> M prose manuscript.

A is distinct because it is the terminal planning object for author review.

Verdict:
SEPARATE REVIEW OUTLINE SURVIVES MTA.
