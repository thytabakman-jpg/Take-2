- "best": selector is otherwise hidden. Resolved provisionally as highest expected target-result value under current canonical project goal, evidence accessibility, dependency position, and cost. OPEN if another selector is intended.

- "meaningful stage": would be ambiguous if left informal. Resolved as a stage that changes evidence state, plan ranking, architecture status, or next-operation basis. Tiny search iterations are not separate stages.
