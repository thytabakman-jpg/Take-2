## Transfer object

PD's cross-stack no-downstream-rescue result applies directly to the current Canonical Authority method:

source package
-> PROFILE / representation
-> TRACE
-> DISCRIMINATE
-> RECOGNIZE
-> COMPOSE.

Let X be the admitted source-package state, R its downstream representation, and T the truth-directed source-ground verdict relevant to the fixed Rashi/Ramban target.

Suppose two admitted source-package states x1 and x2 satisfy

T(x1) != T(x2)

but the source representation or bridge map g collapses them:

g(x1) = g(x2).

Then no later deterministic function h of g(x) alone can recover exact T:

T != h o g.

The result remains true after arbitrarily many later deterministic stages because every later stage receives the same collapsed value for x1 and x2.

## Canonical Authority consequence

A truth-discriminating asymmetry that disappears before or during TRACE cannot be recreated later by DISCRIMINATE, RECOGNIZE, or COMPOSE while those stages see only the collapsed representation.

A later successful discriminator therefore has only three licensed explanations:

1. richer source representation preserving the previously lost distinction;
2. genuinely new independently licensed evidence/acquisition;
3. added bridge/selector/composition machinery whose contribution is attributed to that machinery rather than retroactively to the source package.

This gives a formal information-loss basis for the project's existing distinction between source content and selector/bridge contribution.
