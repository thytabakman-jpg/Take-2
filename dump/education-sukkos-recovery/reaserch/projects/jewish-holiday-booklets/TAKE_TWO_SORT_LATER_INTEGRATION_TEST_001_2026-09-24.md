## What SORT_LATER can capture here

A new side finding encountered during active booklet work becomes a Sort Later candidate only when its destination is not yet safely determined.

Example:

During Keva release QA, a new observation appears that potentially affects the series-wide visual system but it is unclear whether it is:

- a one-page artifact defect;
- a booklet-level house-fit issue;
- a series-level style constraint;
- or a broader production-system issue.

Immediate global classification would interrupt the active release.

Correct action:

minimal capture
→ preserve exact source/context
→ classify as candidate materiality
→ identify candidate destinations
→ assign review trigger
→ return to Keva release work.

The item does not alter the Keva release until the review trigger fires and its actual destination is resolved.

## Failure mode test

### Bad implementation

Use SORT_LATER for:

- unresolved work that already has a correct destination;
- research questions that belong in an open-question register;
- known defects awaiting ordinary repair;
- backlog items;
- every interesting discovery.

This would merely move routing failure into another file.

### Correct implementation

SORT_LATER is a temporary unresolved-intake pressure valve.

Its successful use reduces:

- active-work interruption;
- premature classification;
- false canonicalization;
- cross-project hijacking;
- loss of side discoveries.

It does not reduce:

- known work backlog;
- open research;
- authorized repair;
- material-event accounting;
- project-state updates.

That is a positive result.

The project already has strong specialized destinations for its known problems. Moving those problems into SORT_LATER would weaken the system.

The real value of SORT_LATER is handling the next unexpected side discovery without forcing the active booklet run to stop.

## Success condition

Sort Later succeeds when it preserves a genuinely unresolved side finding without:

- creating a second backlog;
- stealing authority from the specialized destination;
- interrupting the active teaching/release objective;
- allowing unresolved material to disappear;
- becoming a substitute for ordinary routing.
