## Canonicality rule

Candidate work never replaces a canonical page automatically.

A replacement becomes canonical only after explicit user approval such as:
"swap page 2 in the booklet for this new page 2."

## Swap protocol

When a page is approved:

1. Preserve the existing canonical version unchanged.
2. Create the next immutable canonical version folder.
3. Carry forward every unchanged page by exact identity.
4. Replace only the explicitly approved page.
5. Record the new file identity, SHA-256, and generation ID.
6. Update this file and CURRENT_STATE.md.
7. Never assemble a booklet from mixed canonical versions.
