# Take-4

Take-4 is ICC's informed-reconstruction experiment.

It may use the full evidence accumulated in Reaserch and Take-2, but it does not inherit their repository architecture automatically.

## Frozen objective

Given a broad task and a large evolving external corpus, recover the correct current object/state, resolve authority, select the minimum sufficient capability/package, execute under license, verify, update state, and reselect.

## What is inherited

Evidence and demonstrated distinctions may be inherited.

Files, registries, controllers, tool names, and folder structures are not inherited merely because they exist.

## Initial evidence-supported candidate

Take-4 begins from the distinctions that have repeatedly changed results:

1. Episode — frozen task, corpus boundary, evaluation context, protected behavior.
2. Object — exact identity/currentness of result-sensitive things.
3. Evidence — provenance-bearing observations/findings with epistemic status.
4. Authority — explicit ownership/license for consequential operations.
5. Decision — eligible alternatives and preserved incomparable frontier.
6. Transition — baseline-bound attempted state change.
7. Verification — protected-result and target-effect evidence.
8. State Delta — persistent semantic change plus reentry trigger.

These are candidate semantic coordinates. They need not become eight independent registries.

## Loop

ORIENT
→ NAVIGATE
→ RESOLVE
→ SELECT
→ EXECUTE
→ VERIFY
→ UPDATE
→ RESELECT

Reaserch remains an external corpus/authority source. Take-4 must demonstrate that it can navigate it rather than absorbing it wholesale.
