# Experiment 004 — Minimal Closed Loop

Experimental executable witness for the M0-M11 map review.

This is deliberately small. Its job is not to simulate a production research system. Its job is to test whether controller selection, typed authority change, worker binding, post-state observation, verification, state update, reselection and termination can exist in one inspectable trace.

Run:
python3 experiments/004-closed-loop/loop.py

A passing run is runtime evidence only for this fixture and implementation. It is not promotion evidence for a general ICC.
