# Experiment 001 — REBT × Is/Ought vertical slice

Date: 2026-09-24
Status: COMPLETED_ANALYTIC_SLICE
Legacy authority remains: thytabakman-jpg/Reaserch/projects/rebt-is-ought

## 1. Frozen job

Target proposition family: REBT demandingness judgments and normative-support judgments.

Frozen question:

> Does classifying a belief as REBT demandingness determine that the belief instantiates
> an unsupported normative transition?

This is deliberately narrower than the whole REBT × Is/Ought project. The slice tests
whether Take-2 can preserve a real research result through Observe -> PD -> Decide ->
Transition -> Verify -> Observe without migrating the project.

Protected legacy results:
- demandingness is not mere should/must/ought wording;
- normative support and demandingness are distinct coordinates;
- clinical consequence defines neither coordinate;
- later therapeutic supplementation cannot be projected backward.

## 2. OBSERVE

Legacy evidence already contains discriminating cases:
- supported ordinary ought + demanding absolute extension;
- unsupported soft ought + NOT_DEMANDING;
- predictive/emphatic must with NO_TARGET;
- distress without a normative target;
- time-indexed therapist supplementation.

Observation boundary: the promoted/reconciled legacy artifacts only. No new empirical
REBT-source claim is asserted by Take-2.

## 3. FREEZE / TYPE

Objects:
- R = REBT demandingness classification. Psychological/theoretical classificatory status.
- S = normative-support status under an explicit STANDARD_ID. Normative/inferential status.
- D = deontic-introduction pattern/process. Mechanism/transition status.
- C = clinical consequence. Empirical outcome vector.

PD A01 result: R, S, D, and C are not peer labels for one property.

PD A08 remains experimental, so referent-continuity claims are inherited only where the
legacy canonical project already protects them.

## 4. PD DISCOVERY / CHALLENGE

### A02 hidden dependency
Any inference R -> unsupported-S requires a bridge from REBT's demandingness criterion to
the selected normative-support standard. No such universal bridge is present in the
frozen evidence.

### A03 representation attack
Lexical representation ("must/should/ought") collapses alethic, emphatic, institutional,
recommendatory, and demanding uses. Proposition segmentation plus modal/deontic typing
changes verdicts. Therefore lexical force is not a safe representation.

### A04 result sensitivity
Result-changing coordinates include:
- absolutism/unconditionality;
- normative STANDARD_ID;
- proposition segmentation;
- attribution time;
- modal/deontic type.
Clinical consequence does not determine the target relation on current evidence.

### A05 robust localization
The stable divergence is between R and S, not between REBT and all normative reasoning.

### A06 rival clean-sheet reconstruction — EXPERIMENTAL
Rival H1: demandingness just is unsupported normative force.
Rival H2: demandingness tracks absolutism/rigidity and can cross-cut normative support.
Rival H3: apparent divergence is an artifact of proposition segmentation or standards.
Frozen cases discriminate against H1 because supported oughts can receive demanding
extensions and unsupported soft oughts can remain non-demanding. H3 remains a live
methodological sensitivity question rather than a global rescue.

### A09 recurrence
Repeated collapse attempts reappear through wording, distress, therapist attribution,
and is/ought language. The upstream recurring defect is premature coordinate identity,
not one local miscoding.

### A12 spine
classification task -> exact R bearer/criterion
                    -> exact S standard
                    -> proposition/attribution identity
                    -> cross-coordinate bridge
                    -> R/S relation result

The cross-coordinate bridge is downstream of independently fixing R and S.

### A18 / HF-001
Recursive reattack finds a stronger question than simple identity:
what mapping from S plus absolutism/rigidity/modal type/etc. to R is licensed?
That is the legacy project's current higher ceiling and remains OPEN pending systematic
REBT source reconstruction.

## 5. DECIDE

Analytic disposition:

REJECT universal implication:
  R_DEMANDING -> S_UNSUPPORTED

REJECT converse universal implication:
  S_UNSUPPORTED -> R_DEMANDING

PRESERVE:
  R and S are distinct, potentially interacting coordinates.

OPEN:
  exact mapping function and whether S independently contributes to REBT classification
  after other properties are controlled.

No mutation of the legacy REBT project is licensed by this experiment.

## 6. TRANSITION

Take-2 performs one consequential state transition only:
record this bounded research result as a Take-2 experiment result and link it to the
legacy authority as evidence/reference. It does not import the project.

Transition authority: Take-2 experiment scope.
Protected: legacy project authority and all frozen results.
Validator: kernel fitness + A16 analytic verification.

## 7. VERIFY / A16

Counterexample preservation:
- supported ought + demanding extension remains representable;
- unsupported soft ought + non-demanding remains representable;
- NO_TARGET remains distinct from OPEN;
- distress cannot decide R or S;
- later attribution cannot rewrite earlier state.

Regression result: PASS relative to frozen legacy evidence.

Overclaim check:
This experiment does not establish REBT's full rationality architecture, causal theory of
distress, a unique normative standard, or empirical clinical effects.

## 8. RTC v2 ceiling reentry

R0: "REBT demandingness = unsupported is->ought."
Rejected by frozen divergent cases.

R1: "R and S are independent."
Too strong: distinct does not imply probabilistic/logical independence.

R2: "R and S are distinct coordinates with no universal implication licensed by current
evidence; exact interaction remains OPEN."
Accepted local result.

R3: estimate mapping R=f(S, absolutism, rigidity, modal type, empirical/pragmatic
coordinates, attribution context).
Stronger research target, but blocked on systematic REBT source reconstruction and
independent empirical/coder evidence.

Current ceiling: R2 as result; R3 as next research frontier.

## 9. Multi-object relation challenge

Licensed:
D can generate candidate normative content without settling S or R.
S can be compared with R after standards and bearers are fixed.
C can test downstream significance without defining S or R.
PD audits the representation, bridges, selectors, and OPEN coordinates.

Not licensed:
D = S; S = R; R = C; C -> rationality; lexical must -> demandingness.

No single common property replaces the four typed objects.

## 10. Kernel experiment result

The slice used:
- one legacy reference boundary;
- one experiment artifact;
- one common ledger;
- one transition;
- one validator surface.

It did not require importing the REBT project, creating a project-specific state
registry, backlog, workstream registry, audit registry, receipt registry, or migration
copy.

This is preliminary evidence that the minimal kernel can preserve a substantive research
result while keeping PD central and legacy authority intact.
