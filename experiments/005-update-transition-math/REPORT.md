## Kernel result

The existing Take-2 distinction between Event and Transition was useful but incomplete.
The eight-role model reveals a third object: U, the semantic state-transition law.

Event records occurrence.
Transition is a governed attempted/application record.
U determines lawful persistent successor state.

Generic form:

U_K : Sigma_K x D_K partial-> P_nd(Sigma_K)+{NOOP,OPEN,BLOCKED,FAIL,CONFLICT}.

Current basis-relative primitive U families:

1 ACCUMULATE
2 REVISE/REPLACE
3 STRUCTURAL/TOPOLOGY CHANGE
4 RETRACT/INVALIDATE

Rollback is compensation composition, not a primitive.
Merge/reconciliation computes an accepted delta upstream; U applies it.
Atomicity, idempotence/replay, commutation, freshness, authority, verification and
compensation are properties/controls, not update families.

## Kernel architecture implication

Take-2's five durable primitives remain useful. This experiment does NOT add U as a sixth
durable file/object primitive. U is a semantic system role; Transition objects are durable
records/authority surfaces for applications of U.

This respects the design rule that semantic distinctions do not automatically imply new
operating surfaces.
