## 1. Critical gaps

### G-01 Common lifted result carrier
Problem:
Each subsystem currently has local result notation. PD uses result classes/fibers; O uses
partial/set-valued results; C uses judgments/dispositions; U uses state transitions.

Required:
One typed lifted carrier that preserves:
- accepted plural incomparable results;
- OPEN;
- BLOCKED;
- FAIL;
- witnesses/provenance;
- status/disposition;
- protected equivalence;
without identifying statuses with ordinary empty result sets.

Dependency:
Upstream of cross-role composition, C/U interfaces, R output equivalence, basis minimality.

### G-02 Cross-role composition algebra
Problem:
We know the cycle S -> R -> <G,M,O,C> -> U -> S, but do not yet have a complete
composition/type system.

Required:
- legal interfaces;
- type compatibility;
- partial composition;
- identity/null configurations;
- provenance propagation;
- protected-result propagation;
- noncommutation witnesses;
- composition failure semantics.

Dependency:
Requires G-01 and materially constrains all later minimality work.

### G-03 Closure/convergence theory
Problem:
We distinguish basis-relative search closure from result maximality, but do not yet have a
general mathematical account of when iterative execution terminates, reaches a fixed point,
cycles, or licenses stronger closure claims.

Required:
- relative closure;
- fixed-point conditions;
- cycle detection;
- convergence conditions;
- CoverageCertificate semantics;
- distinction between operational termination and mathematical maximality.

### G-04 State sufficiency
Problem:
S has candidate primitive coordinates <RF,SC,PS,ES,OS,H,RS>, but Markov/state sufficiency
has not been proved.

Required:
For equivalent states under the proposed state representation, future U and R behavior

Required:

- noncommutation;
- event equivalence;

- accounting invariant for every material state change.

### G-06 G generator basis

generator algebra is not closed.

Required:
- proposal relation;
- generator provenance;
- family vs sampling-policy distinction;

- reduction of historical generator labels.

### G-07 System-role minimality
Problem:
The eight roles have survived current ablations but are not minimally proved.

Required:
For each role, identify a protected system behavior lost when removed while all other
roles remain. Then test pairwise/macro merges, especially:
R+U, K+C, G+O, M+O, S+U.
