## Purpose

This file answers a narrower question than the bibliography:

> What exactly does each part of the manuscript claim, what kind of claim is it, what evidence does it need, and what currently supports it?

A claim unit is normally one sentence or two tightly dependent sentences. Purely analytic steps are not padded with decorative citations. They are mapped to the source premises on which they depend.

Status:
- **GREEN** — externally verifiable claim supported.
- **GREEN / ANALYTIC** — source premise supported; the stated consequence is the paper's own inference.
- **DEFINITION** — paper-defined object; no external fact citation needed.
- **PROJECT** — claim about this project's own procedure/history; requires project record rather than external source.
- **YELLOW** — plausible/substantially supported, but publication citation or calibration is incomplete.
- **OPEN** — exact supporting evidence still needs acquisition/inspection.
- **REPAIRED** — a fact-check defect existed and has been corrected in the live manuscript.

## Fact-check principle

A citation gap and a factual error are different states.

- A factual error requires manuscript correction.
- A citation gap requires source closure before publication.
- An analytic inference requires a valid argument from supported premises, not an ornamental citation.
- An OPEN project negative must remain corpus- and evidence-bounded.
