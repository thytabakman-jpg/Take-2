# G. What to move earlier

## Section 1.2 can state the answer, not merely the question

The introduction can announce three things immediately:

1. **Methodological thesis:** status alone is insufficient; a usable ground must travel through a source-attributable path to the exact proposition, discriminate the rivals, and be warrantedly usable by the evaluator.
2. **Case result:** in the current seven-family corpus, no admissible package completes that path to C_S.
3. **Broader payoff:** the failure pattern shows why authority transfer across functions requires explicit transfer relations and attribution.

These claims are earned later, but academic introductions routinely state results before demonstrating them.

## Section 2 should become short

Section 2 only needs to establish inherited comparison machinery and the seven-family sample.

It should not feel like a second introduction.

## Section 3 can foreground discoveries rather than merely catalogue sources

Each source paragraph can begin with the result it contributes:

- pluralism can legitimate without selecting truth;
- provenance can classify without selecting;
- authority can bind while error remains possible;
- prophecy shows success is possible;
- Ramban's received tradition reaches the topic but not the exact peshat edge.

This gives the reader new payoff continuously before formal method terminology appears.
